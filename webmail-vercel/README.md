# Outlook Webmail & OTP Viewer (Vercel Edition)

Автономный веб-интерфейс для просмотра почты Outlook / Hotmail и мгновенного перехвата кодов подтверждения (OTP) без необходимости входить в веб-интерфейс Microsoft, проходить капчи или рисковать блокировкой по фингерпринту.

## Возможности
- 🚀 **Развертывание в 1 команду** через Vercel CLI (`vercel` или `vercel --prod`)
- 🔑 **Мгновенный перехват OTP**: коды из писем (Steam, Discord, Telegram, Google и др.) подсвечиваются отдельным бейджем с кнопкой копирования в 1 клик
- 📬 **Полноценный почтовый клиент**: папки (Входящие, Спам, Отправленные, Корзина), поиск по теме/отправителю, просмотр красивого HTML в безопасном iframe
- 🔄 **Автообновление**: опрос новых писем каждые 5, 10 или 30 секунд
- 🌐 **Два режима работы**:
  1. **Автономный Serverless-режим**: Вводите `email----password----client_id----refresh_token` прямо на сайте — Vercel Serverless Function напрямую связывается с Microsoft Graph API (VPS вообще не требуется!).
  2. **Связка с бекендом (Oracle / Render)**: Укажите адрес вашего запущенного бекенда в настройках (например `https://your-app.onrender.com`), и все зарегистрированные авторегом аккаунты автоматически появятся в списке.

## 🚀 Инструкция по развертыванию через Vercel CLI

### Шаг 1. Установите Vercel CLI (если еще не установлен)
```bash
npm install -g vercel
```

### Шаг 2. Авторизуйтесь в Vercel
```bash
vercel login
```

### Шаг 3. Задеплойте проект
Перейдите в папку `webmail-vercel` и выполните:
```bash
cd webmail-vercel
vercel --prod
```
- На все вопросы CLI можно нажимать **Enter** (согласиться с настройками по умолчанию).
- Через 10-15 секунд Vercel выдаст готовую публичную ссылку:
  `https://outlook-webmail-yourusername.vercel.app`

### Шаг 4. (Опционально) Настройка переменных окружения в Vercel
Если вы хотите привязать ваш центральный бекенд на Oracle VPS или Render:
```bash
vercel env add BACKEND_URL
# Введите значение, например: https://your-render-app.onrender.com
vercel --prod
```
Либо укажите URL прямо в веб-интерфейсе в кнопке «Бекенд (Oracle/Render)».

## 🛠 API Эндпоинты на Vercel

| Метод | Путь | Описание |
|---|---|---|
| `POST` / `GET` | `/api/inbox` | Получить список писем (`refresh_token`, `folder`, `search`) |
| `POST` / `GET` | `/api/message` | Получить полное тело письма по `id` (HTML, текст, OTP) |
| `POST` / `GET` | `/api/otp` | Опросить и извлечь проверочный код (`refresh_token`, `service`) |
| `GET` | `/api/accounts` | Список аккаунтов (проксируется на `BACKEND_URL`) |
