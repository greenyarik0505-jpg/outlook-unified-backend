## What's Changed

- Fixed multi-port refresh failures caused by ports already occupied by another process. Occupied ports are skipped and the next available port is selected automatically.
- Added safe port-range handling at port 65535. Port allocation no longer wraps to port 0 and reports a clear error when the range is exhausted.
- Increased conflict retry capacity based on the number of configured nodes and fixed retry exhaustion incorrectly being reported as a successful start.
- Persisted reassigned ports during startup, reload, and port rebuilding so the saved runtime configuration remains aligned with the active listeners.
- Added runtime validation for every imported node, including chained routes, before applying staged results. Nodes that cannot produce a valid sing-box runtime configuration are marked as failed instead of being added to the pool.
- Strengthened runtime verification to require matching node-pool, configured-node, and active-listener sets, using the complete route identity for chained and non-chained nodes.
- Added regression coverage for consecutive occupied ports, external port conflicts, port-range boundaries, runtime synchronization, and import rollback behavior.
- Release packages are provided for Windows and Linux. Each platform includes amd64 and arm64 binaries and ZIP packages, plus SHA-256 checksums.
