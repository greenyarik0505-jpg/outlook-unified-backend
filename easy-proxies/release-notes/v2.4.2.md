## What's Changed

- Fixed shutdown deadlocks between management HTTP requests and the runtime manager. Shutdown now cancels work, drains HTTP outside the manager lock, and serializes cleanup with startup and reload.
- Added bounded, idempotent shutdown for the management server and proper lifecycle cleanup for health checks, session cleanup, and GeoIP routing.
- Close both sides of GeoIP CONNECT tunnels, preserve buffered tunnel data, and release listeners even when a router is stopped immediately after startup.
- Release retained runtime contexts on startup, persistence, reload, and rollback failures.
- Prevent overlapping user batch tests and conflicting source refreshes. The legacy probe-all endpoint now uses a bounded worker pool.
- Create batch rollback snapshots only when applying results, preventing canceled probes from discarding nodes imported while testing was in progress.
- Stop and wait for previous subscription refresh loops during reconfiguration, prevent restarts after shutdown, and wait for the correct refresh generation when saving subscription settings.
- Recognize Windows address-in-use errors and IPv6 bind errors when reassigning occupied proxy ports.
- Added an opt-in `-shutdown-on-stdin-close` flag for launchers that own the proxy process, including a bounded exit fallback.
- Expanded regression coverage and made release-feature race tests and real runtime lifecycle tests part of the release workflow.

## Downloads

Windows and Linux builds are available for amd64 and arm64, with standalone binaries, ZIP packages, and SHA-256 checksums. Existing configuration files remain compatible.
